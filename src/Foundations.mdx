# Foundations

This is the source-of-truth layer. Every value here comes from `tokens/primitive.json` and
`tokens/semantic.{light,dark}.json`, compiled through Style Dictionary (`npm run tokens`) into
`src/tokens/*.css` — the same files this Storybook and any consuming app import. **Nothing below
is a hard-coded value in a component.**

## Token architecture

1. **Primitive** — raw ramp values (`color.primary.700`, `spacing.4`, ...). Never used directly in components.
2. **Semantic** — purpose-mapped, mode-aware (`color-bg-primary`, `color-text-critical`, ...). Two modes: `light` and `dark`, same names, different primitive references.
3. **Utility** — single-mode, non-ramp values (`color-utility-alpha-black-10`, ...) for one-off needs like hover overlays and dividers that don't belong on a semantic ramp. Utility tokens live in the same collection as Primitives, but unlike the raw ramps, they're **designed to be bound directly** in components — that's the one exception to rule #1.
4. **Component** — (next step) component-scoped aliases of semantic tokens for full re-skinning isolation.
